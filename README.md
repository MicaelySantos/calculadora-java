# Calculadora em Java ☕

Projeto de uma calculadora simples desenvolvido em Java para praticar conceitos básicos de programação.

## Sobre o projeto

A calculadora funciona pelo terminal e permite realizar diferentes operações matemáticas por meio de um menu interativo.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Potenciação
- Raiz quadrada
- Porcentagem

## Tecnologias utilizadas

- Java
- IntelliJ IDEA

## Conceitos praticados

- Variáveis e tipos de dados
- Entrada de dados com Scanner
- Estruturas condicionais (if/else)
- Switch case
- Laços de repetição (do while)
- Operações matemáticas

## Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Abra o arquivo `Main.java`.
3. Clique em Run para executar o programa.
4. Escolha uma operação no menu e digite os números solicitados.
